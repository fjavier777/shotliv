# Shotliv Privacy Policy

**Effective date:** November 20, 2026

## 1. Overview

Shotliv is a Chrome extension that allows users to enhance images directly in their browser.

This Privacy Policy explains how Shotliv handles information when users interact with the extension.

## 2. Information Processed

When a user selects an image, Shotliv accesses the selected file and its filename solely to provide image preview, editing, and download functionality.

Supported image formats are JPEG, PNG, and WebP.

Image processing takes place locally in the user's browser using built-in browser technologies.

## 3. Data Collection and Sharing

Shotliv does not collect, upload, transmit, or share selected image files or their contents with Shotliv servers, the developer, or third parties.

The extension does not use:

- User accounts or authentication.
- Analytics or advertising trackers.
- Cookies for tracking.
- External image-processing services.
- Cloud storage or remote image processing.

## 4. Local Processing and Storage

Selected images are processed in the browser's memory during the active editing session.

Shotliv does not store image files in persistent storage or upload them to cloud services.

When a user downloads an enhanced image, the download is handled by Chrome and saved according to the user's browser settings.

## 5. Permissions

Shotliv requests no optional or broad browser permissions.

The extension uses its Chrome extension functionality to open the editor. Users select image files themselves through the browser's file selection interface.

## 6. Third-Party Services

Shotliv does not integrate with third-party services that receive or process user-selected images.

## 7. Changes to This Policy

This Privacy Policy may be updated if the extension's functionality or data practices change.

Any material changes will be reflected in the published policy.
